Test Panel gsm_1.0.2
#
Структура:
app.py
requirements.txt
logpass.txt
#
Если под «py6» имеется в виду Python 3.6, этот набор зависимостей выбран для совместимости с Python 3.6.x.
#
Установка:
1. Установи Python 3.6.x.
2. Открой CMD в папке проекта.
3. Выполни:
   python -m pip install -r requirements.txt
4. Запусти:
   python app.py
#
Формат logpass.txt:
login:password
login2:password2
#
Пароли не отправляются в браузерный JavaScript: API отдаёт только login и status.
